# 随机抽签器

一款基于 Python + Tkinter 开发的**可视化随机抽签小工具**，界面简洁、逻辑严谨，适用于日常随机抽签、随机点名、随机分配场景。

> 📖 **详细使用教程**：[使用说明.md](使用说明.md) — 面向用户的分步操作、配置与常见问题

## ✨ 项目特点

- **等概率不放回抽取**：每个号码出现的概率完全相同，一轮抽完不会重复

- 内置黑名单：自动跳过指定禁用号码

- 可视化剩余数量提示，实时展示抽取状态

- 一键重置数字池，操作简单

- 配置热加载：改完 `config.json` 保存即生效，无需重启

- 内置关于页面，展示开源协议与项目地址

- 原生 GUI 界面，Windows/Linux 已适配（macOS 基于 Tkinter 跨平台可运行，但**未做专项适配、未实测**）、无广告、纯轻量

- 化学课特供版：长按悬浮窗直接打开，闪现**假启动日志**（Arch systemd 风格 + Windows 日志内容）+ 标题加后缀 + 输入幸运数字（只抽该数字）

- **位图绘制抗锯齿**：Windows 高 DPI 感知 + 悬浮圆球 PIL 超采样渲染，高分屏下文字/圆边不再马赛克、锯齿

- **自适应缩放**：窗口大小跟随 1/2 逻辑分辨率（宽高占屏幕一半），字体大小随窗口等比缩放；悬浮窗**右键**也可直接打开化学课特供版；**数字小键盘弹窗尺寸/字体同样随窗口缩放**（按内容自适应，始终露出确定按钮）

- **加密持久化**：累计抽签记录保存到程序目录 `history.json`（随机 IV + 流密码 + HMAC 校验，密钥不落盘），重启保留、文件不可读明文

- **轮次隔离**：上一轮不满 20 抽就重置时，下一轮排除上轮已抽号码，不再抽到刚抽过的人

## ⚙️ 配置文件

`config.json` **由程序首次运行自动生成**（无需手动创建或随包复制），可在「帮助 → 编辑配置文件」中直接修改：

| 字段 | 说明 | 默认值 |
| --- | --- | --- |
| `pool_min` | 号码下界 | `1` |
| `pool_max` | 号码上界 | `54` |
| `excluded` | 黑名单，这些号码不会被抽到 | `[37, 39, 50, 54]` |

抽签为**不放回**模式：抽中的号码离开号码池，直到抽完或点击重置。

### 公平性说明

不放回模式下，每轮只抽一部分人，**数学上必然有约一半人和上一轮重复**——
这是抽签规则本身决定的，调整随机算法消不掉。

能做的是让「谁被重复」在长期内摊平。程序记录每个号码的累计被抽次数，
抽中某号码时它的权重除以 `FAIRNESS_DECAY`（默认 2.0）：**被抽得越少，权重越高、
越容易被抽到**。

实测（50 个候选号，每轮抽 25 次，2000 轮）：

| 指标 | 纯随机 | 加权（当前） |
| --- | --- | --- |
| 相邻两轮重复数 | 12.50 | 11.18 |
| 各号码出现频次极差 | 64 | 3 |
| 频次标准差 | 18.06 | 0.61 |

权重是**渐进的**而非严格轮换：严格轮换会让第 2 轮恰好抽中第 1 轮的补集，
形成两轮循环——抽到的永远是同样那批人，只是顺序不同。

**轮次隔离**：若上一轮**不满 20 抽**就点「重置」开始新一轮，新池子会**排除**上一轮已抽中的号码，避免「抽了几个就重开、下一轮又抽到同样的人」；抽满 20 抽则恢复正常全池，长期公平不受影响。

**累计记录持久化（加密）**：每个号码的累计被抽次数会保存到程序目录 `history.json`，**加密存储**（随机 IV + 流密码 + HMAC 校验，密钥不落盘），直接打开文件看不到记录内容；重启程序后自动恢复，继续沿用加权公平。若想彻底清空记录，可用「更多 → 停止进程」退出后删除 `history.json` 再重开。

## 🧪 化学课特供版（长按悬浮窗直接打开）

1. **长按悬浮窗约 0.8 秒**（不拖动）**直接打开**化学课特供版，每次长按都重新打开

2. 打开时**闪现一个终端窗口**，快速刷过一段**假启动日志**（`Microsoft Windows [Version 10.0.19045.4046]` + 绿色 `[  OK  ]` / 红色 `[FAILED]` 的 Windows 服务/启动项，Arch systemd 风格排版，约 0.5 秒，快得看不清）后自动关闭

3. 标题加上「 · 化学课特供版」后缀；**待终端关闭后**再弹出**屏幕居中的数字小键盘窗口**（仅保留确定按钮），点选 0-9 输入幸运数字（含清空/删除，须在候选范围内，非法输入会被拒绝），点确定**立即弹出主窗口并打开**化学课特供版

4. 开启后**只会抽到该幸运数字**；界面按**标准版样式**显示（结果行、剩余行无花哨专属文字，仅窗口标题带后缀）；再次长按可重新输入；帮助菜单也可恢复正常版

5. **关闭窗口自动回退标准版并最小化到悬浮球**（进程持久化，不退出；化学课特供版状态不持久化，仅本次运行生效）

## 🚀 使用方法

### 1. 源码运行

```bash
python random_draw.py
```

### 2. 运行测试

```bash
python -m unittest discover -p "test_*.py"
```

### 3. 打包成 Windows EXE

#### 方式一：GitHub Actions（推荐，无需本地 Windows，可自动发布）

仓库已配置 `.github/workflows/build-exe.yml`。推送到 `main` 后会自动：

1. 在 Ubuntu 上跑单元测试
2. 在 Windows runner 上并行打包（PyInstaller 与 Nuitka 各一份）
3. 产出 `RandomDraw-pyinstaller` 与 `RandomDraw-nuitka` 两个 artifact

**打一个 `v*` 标签**（如 `git tag v1.10 && git push origin v1.10`）时，CI 会额外**自动创建 GitHub Release** 并把打包好的 exe 上传到 Release 页面；也可在 Actions 页面点 **Run workflow** 手动触发。

两个版本各有取舍：**Nuitka** 编译为原生代码，杀软误报率明显更低（推荐分发用）；
**PyInstaller** 产物更小、构建更快。

#### 方式二：本机手动打包（不依赖版本库脚本）

```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name RandomDraw random_draw.py
```

或用 Nuitka：

```powershell
pip install nuitka
python -m nuitka --standalone --onefile --windows-disable-console --enable-plugin=tk-inter --assume-yes-for-downloads --output-filename=RandomDraw.exe random_draw.py
```

> 本机开发用的 `build.sh`（Linux/Wine）与 `build.bat`（Windows）属于**本地构建工具**，写死了本机路径，**未纳入版本库**（已加 `.gitignore`）；需要时可在本地保留使用，但公开构建以 CI 为准。

**`config.json` 不随包复制**——程序首次运行在自身目录自动生成默认配置（含黑名单），无需手动创建。
